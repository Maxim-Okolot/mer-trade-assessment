# mer-trade-assessment

Тестовые задания: разбор инцидентов поддержки, сверка заказов с 1С и идея
улучшения с прототипом. Каждую работу можно проверить одной командой.

## Быстрый старт

Нужны Windows и PowerShell 5.1+. PHP 8.1+ желателен, но не обязателен:
скрипт проверки сам скачает портативную сборку, если PHP не найден.

Из корня репозитория:

```cmd
run.cmd
```

или, если PowerShell разрешает локальные скрипты:

```powershell
.\run.ps1
```

Отдельные работы:

```cmd
run.cmd -Task 01
run.cmd -Task 06
```

Если PHP нет, `run.cmd` сам скачает портативную сборку в `.tools\php`
(каталог исключён из git). Запретить скачивание: `run.cmd -NoBootstrap` —
тогда PHP 8.1+ нужно установить вручную и добавить в PATH.

## Что должно получиться

**Задание 01 — сверка заказов с номенклатурой 1С.** В консоли отчёт
по 31 заказу: 16 готовы, 9 требуют проверки, 4 заблокированы, 2 пропущены.
Код возврата `1` — это норма: есть заблокированные заказы.

**Задание 06 — мониторинг расхождений.** Первый запуск строит базовую линию
(14 расхождений по 13 заказам), второй — показывает диф по новому срезу:
новых 1, исправлено 2. Код возврата `2` — это норма: есть новые расхождения.

Все отчёты, снимки и логи пишутся в `var\` (каталог исключён из git):

| Файл | Что это |
|---|---|
| `var\01-report.csv` | отчёт по заказам для Excel |
| `var\01-report.txt` | тот же отчёт текстом |
| `var\01-app.log` | лог сверки |
| `var\monitor-state.json` | снимок расхождений после базовой линии |
| `var\monitor.log` | лог мониторинга |

Примеры отчётов также лежат в репозитории: `01-orders-1c-sync/output/`
и `06-open-improvement/prototype/output/`.

## Работы

| Папка | Что внутри |
|---|---|
| `01-orders-1c-sync/` | PHP-скрипт сверки заказов с 1С, исправленные баги `OrderTotal.php`, README с решениями |
| `04-support-incidents/` | разбор четырёх обращений по логам, `04-incidents.md` |
| `06-open-improvement/` | записка с идеей мониторинга расхождений и прототип на PHP |

Подробности запуска — в README каждой папки.

## Запуск без обёртки

```powershell
# сверка заказов
php 01-orders-1c-sync\bin\check-orders.php

# мониторинг: базовая линия, затем диф
php 06-open-improvement\prototype\monitor-discrepancies.php --baseline
php 06-open-improvement\prototype\monitor-discrepancies.php --orders=06-open-improvement\prototype\fixtures\orders-next.json

# самопроверка исправленных багов
php 01-orders-1c-sync\bugs\OrderTotal.php
```

Если PHP нет в PATH, используйте `..\.tools\php\php.exe` или путь,
который вывел `run.cmd`.

## Структура

```
.
├── run.cmd, run.ps1        # проверка одной командой
├── 01-orders-1c-sync/      # задание 01
├── 04-support-incidents/   # задание 04
└── 06-open-improvement/    # задание 06
```

`.tools/` (портативный PHP) и `var/` (результаты запусков) в git не попадают.
